# F1 Fantasy Ціни

Свій трекер цін F1 Fantasy: щодня збирає ціни й очки всіх пілотів і команд,
рахує, хто як подорожчав, виводить пороги зміни ціни і показує на сайті,
скільки очок треба кожному на наступному етапі, щоб подорожчати.

## Як це працює

1. **Збирач** (`collector/collect.py`) відкриває сторінки статистики гри у
   headless-браузері й перехоплює всі JSON-відповіді, які завантажує сайт.
   Тобто API шукати вручну не треба: збирач сам знаходить потрібні запити,
   витягує з них гравців з цінами й зберігає знімок у `data/snapshots/`.
2. **Аналіз** (`analysis/analyze.py`) порівнює знімки: очки за кожен етап,
   зміна ціни після нього, середні очки на мільйон за останні 3 етапи.
   З цього виводяться пороги для кожної цінової категорії.
3. **Сайт** (`site/index.html`) показує таблицю, історію цін і калькулятор
   «якщо набере N очок → ціна зміниться на X».
4. **GitHub Actions** запускає все це щодня безкоштовно й публікує сайт на
   GitHub Pages.

## Запуск (5 хвилин, один раз)

1. Зареєструйся на github.com, якщо ще немає акаунта.
2. Створи новий репозиторій: **New repository** → назва, наприклад
   `f1-fantasy-tracker` → **Public** → **Create repository**.
3. На сторінці репозиторію натисни **uploading an existing file** і перетягни
   туди **вміст** розпакованої папки (не саму папку). Важливо: папка
   `.github` прихована — у Windows увімкни «Показувати приховані елементи»,
   на Mac натисни Cmd+Shift+. у Finder. Натисни **Commit changes**.
4. **Settings → Pages** → у полі **Source** вибери **GitHub Actions**.
5. **Settings → Actions → General** → внизу **Workflow permissions** →
   **Read and write permissions** → **Save**.
6. Вкладка **Actions** → зліва «Збір даних F1 Fantasy» → **Run workflow**.
7. Коли запуск завершиться (2–3 хв), сайт буде за адресою
   `https://<твій-логін>.github.io/f1-fantasy-tracker/`.

Далі все працює саме: щодня о 11:17 за Києвом.

## Якщо збір не спрацював

Сайт гри може змінитися або не віддати дані ботові. Тоді:

1. Відкрий невдалий запуск у вкладці **Actions**.
2. Унизу в **Artifacts** завантаж `debug-…`. Там скріншоти сторінок
   (`debug/page_*.png`) і всі перехоплені відповіді сайту
   (`data/raw/*/discovered_endpoints.json`).
3. Скинь мені лог і цей архів — поправлю збирач під реальну структуру.

## Важливо знати

- **Пороги спочатку — припущення** (`config.json` → `assumed_rules`).
  Після ~3–4 етапів збору аналіз починає виводити їх із реальних змін цін
  і на сайті з'являється позначка «з даних».
- Перший знімок — лише точка відліку. Зміни цін з'являться після наступного
  етапу.
- Це неофіційний інструмент. Не запускай збір надто часто (раз на день
  більш ніж достатньо).

## Локальний запуск (за бажанням)

```bash
pip install -r requirements.txt
python -m playwright install chromium
python collector/collect.py
python analysis/analyze.py
python -m http.server -d site 8000   # відкрий http://localhost:8000
```
